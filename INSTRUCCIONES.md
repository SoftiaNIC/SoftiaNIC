# Instalación del README de perfil de sof.ia

## Organización de GitHub

Copia el contenido de esta carpeta dentro del repositorio especial de perfil:

```text
.github/
└── profile/
    ├── README.md
    └── assets/
        ├── hero.svg
        ├── metrics.svg
        ├── services.svg
        ├── comparison.svg
        ├── process.svg
        └── footer.svg
```

GitHub mostrará automáticamente `profile/README.md` en la página principal de la organización.

## Antes de publicar

1. Confirma que las métricas `7+`, `150+`, `50+` y `30+` continúan vigentes.
2. Sustituye los enlaces de cada proyecto por repositorios o casos de estudio cuando estén disponibles.
3. Mantén las imágenes remotas del sitio o descárgalas al repositorio para evitar dependencias externas.
4. Verifica el README tanto en modo claro como oscuro.
